What Syntag is

A lightweight tool for adding visible, standardized AI-content disclosures without turning the label itself into advertising.

A neutral marking layer for trustworthy digital attribution.

Syntag is designed around a simple convention: say whether AI was involved, whether content is fully generated, or whether existing content was modified. Choose a tag theme suited to the publishing context and export a marked asset.

Developer surface

Defaults first. Settings when needed.

The browser API and local MCP-shaped JSON-RPC bridge use the same settings model as the interface. If no options are passed, Syntag uses the current defaults.

Browser API

Available as window.Syntag. Pass a File and optional settings. The result is a Blob plus metadata.

const result = await Syntag.process(file); // defaults: generated · standard · bottom-right · medium const custom = await Syntag.process(file, { level: "modified", theme: "eu", position: "bottom-right", size: "large", opacity: 1, sidecar: true }); Syntag.download(custom);

MCP local bridge

A browser-only MCP-shaped handler for prototyping tool calls. It implements tools/list and tools/call locally; a real stdio/HTTP MCP transport still requires a host process.
